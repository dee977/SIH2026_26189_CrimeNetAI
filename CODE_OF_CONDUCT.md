# Code of Conduct

## Our Pledge

We are committed to maintaining a professional, respectful, and inclusive environment for everyone contributing to CrimeNet AI.

## Our Standards

### Expected behavior

- Be respectful and professional.
- Use welcoming and inclusive language.
- Accept constructive feedback.
- Focus on project goals and technical quality.
- Respect different perspectives and skill levels.
- Report security concerns responsibly.

### Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Offensive, abusive, or hateful comments.
- Publishing others’ private information without consent.
- Sharing confidential credentials, API keys, or private datasets.
- Deliberate misinformation or misleading technical claims.
- Disruptive behavior in discussions, issues, or pull requests.

## Responsibilities

Project maintainers are responsible for clarifying acceptable behavior and may remove, edit, or reject comments, commits, code, issues, and contributions that violate this Code of Conduct.

## Reporting

Report unacceptable behavior to the project maintainers through GitHub Issues or team communication channels.

All reports will be reviewed and handled with appropriate discretion.

## Attribution

This Code of Conduct is adapted from common open-source community standards and may be updated as the project grows.
