# SIH Demo Script — CrimeNet AI

## Demo Duration

3–5 minutes

## Demo Objective

Show that CrimeNet AI can securely connect fragmented investigation data, discover relationships, preserve evidence integrity, and generate explainable investigative leads.

## Demo Flow

### 1. Problem Introduction — 30 seconds

“Investigators receive fragmented data from FIRs, CDRs, bank transactions, and documents. CrimeNet AI connects this data into a secure case-scoped intelligence platform.”

### 2. Case Creation — 30 seconds

- Create a new case.
- Add investigator and analyst.
- Show role-based access control.

### 3. Evidence Upload — 45 seconds

- Upload FIR or CDR document.
- Show SHA-256 hash generation.
- Show evidence metadata.
- Show ingestion status.

### 4. Case Graph — 60 seconds

- Open the Network Graph.
- Select a person.
- Show case-scoped relationships.
- Run a multi-hop path analysis.
- Show source records behind a relationship.

### 5. Investigative Lead — 60 seconds

- Show financial transaction path.
- Show communication overlap.
- Show timeline correlation.
- Explain that this is an investigative lead, not proof of guilt.

### 6. Grounded AI Assistant — 45 seconds

Ask:

```text
What financial relationships does Person P00001 have?
```

Show:

- Retrieved transactions
- Retrieved communication records
- Source IDs
- Evidence references

Then ask about a person with no available data and show:

```text
INSUFFICIENT EVIDENCE / DATA NOT FOUND
```

### 7. Evidence Verification — 30 seconds

- Open Evidence Vault.
- Verify SHA-256 hash.
- Show chain-of-custody events.
- Generate investigation report.

## Key Messages

- Real case isolation
- Real evidence integrity
- Explainable graph intelligence
- Grounded AI with citations
- Human-in-the-loop investigation
- No guilt scores or automated criminal judgments

## Claims to Avoid

- “AI predicts criminals.”
- “The system detects guilt.”
- “The system is court-admissible.”
- “The system provides real-time surveillance.”
- “Graph neural networks improve accuracy” without measured evaluation.
