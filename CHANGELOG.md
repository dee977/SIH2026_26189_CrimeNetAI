# Changelog

All notable changes to CrimeNet AI are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-10-04

### Added

- Initial CrimeNet AI project structure.
- React + Vite frontend workspace.
- FastAPI backend APIs.
- PostgreSQL/Supabase application database.
- Neo4j criminal-network graph.
- Case management and investigation workspace.
- Role-based access control.
- Case-membership authorization.
- Entity Explorer.
- Network Graph visualization.
- Timeline analysis.
- CSV ingestion pipeline.
- Financial transaction analysis.
- Communication record analysis.
- FIR relationship analysis.
- Graph analytics.
- Community detection.
- Centrality analysis.
- Evidence upload and SHA-256 hashing.
- Evidence metadata and verification workflow.
- Supabase Storage integration.
- Audit logging.
- AI-assisted investigation workflow.
- Investigation report generation.
- Render deployment configuration.

### Security

- JWT-based authentication.
- Backend-enforced case isolation.
- Role-based access control.
- Private evidence storage.
- Short-lived signed URLs for evidence access.

### Known Limitations

- OCR accuracy depends on document quality.
- Entity resolution requires investigator review.
- AI findings require human verification.
- GIS precision depends on available source-location data.
- Demo datasets are synthetic/development datasets and are not real production data.
